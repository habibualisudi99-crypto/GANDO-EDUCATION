Ili kulifanya APK, kwanza chapisha mafaili haya kwenye GitHub Pages yenye HTTPS,

Masomo, notes, mitihani na matokeo bado ni sehemu za kuendelezwa; mada zilizopo ni orodha ya kuanzia.
