# GANDO EDUCATION

GANDO EDUCATION - Learning Platform for Form I-IV.

## GitHub Pages
Keep `index.html`, `manifest.webmanifest`, `sw.js`, and the `icons/` folder together in the published site root.

## PWA installation
After publishing the updated files over the existing GitHub Pages site:
1. Open the site in Chrome.
2. Refresh the page and wait a few seconds.
3. Open Chrome menu > Install app (or Add to Home screen).
4. If an old GANDO shortcut is already on the home screen, remove it first and create a new one to use the updated icon.

The service worker caches the main page and app icons for basic offline access after the first successful visit.

Note: this update fixes the install metadata and app icons. Lessons, exams, and student results still need their actual learning content and functionality added.
